# 🦊 Foxify — Spotify Connect для Яндекс Станции Мини 2

Автономный, оптимизированный сервис **Spotify Connect** на базе официального движка **Spotify Soloist** для умных колонок **Яндекс Станция Мини 2** (а также других устройств на ARMv7 / Cortex-A35 / Allwinner / Amlogic).

Пакет для менеджера [YAM](https://github.com/nyakokitsu/yam): `avelc/foxify`.

---

## 🌟 Особенности Foxify

1. **Без тяжёлого PulseAudio (Zero-Bloat)**:
   - Стандартный сервер PulseAudio требует 40–60 МБ оперативной памяти и падает с OOM на устройствах со 128–256 МБ RAM.
   - В Foxify включена кастомная сверхлёгкая библиотека **`libpulse.so.0`**, перехватывающая аудиопоток и направляющая его напрямую в системный звуковой тракт ALSA (`pcm.!default` с `softvol Master` и `dmix`).
   - Потребление памяти: **всего ~18–25 МБ RAM**!

2. **Максимальное качество звука (320 kbps High Fidelity)**:
   - Принудительно активирован максимальный битрейт **Extreme (320 kbps Ogg Vorbis)**.
   - Включён алгоритм защиты от клиппинга: **-6.0 dB цифровой хедрум (0.50x)** перед аппаратным моно-суммированием `Lane0 Mix (Left + Right)`, что полностью исключает интерсемпловый клиппинг и перегруз на громких современных мастерах.
   - Настроен высококачественный DSP-ресемплер ALSA **Speex (`speexrate_medium`)**, устраняющий металлический алиасинг при конвертации 44.1 кГц → 48 кГц.

3. **Экспериментальная перцептивная кривая громкости (`foxify curve on`)**:
   - По умолчанию используется стандартная линейная шкала (1:1 со слайдером Spotify).
   - Опционально можно включить психоакустическую степенную кривую ($\gamma = 1.5$): тихие уровни (1–15%) дают точную, плавную регулировку для комфортного ночного прослушивания без резких скачков. Переключается в один клик: `foxify curve on` / `foxify curve off`.

4. **Аппаратная калибровка усилителя Silergy SY6045S / TAS5805M**:
   - Активированы родные аппаратные профили **`SPK EQ on`** и **`SPK DRC on`**, компенсирующие акустику компактного пластикового корпуса Станции Мини 2 и защищающие динамик от искажений.
   - Калиброванный уровень мощности усилителя (`SPK Master` = 240 / -7.5 dB) обеспечивает широкий динамический диапазон без фонового шипения.

5. **Офлайн голосовое управление (Voice Spotter)**:
   - Встроенный слушатель аппаратного споттера ловит ключевые слова («дальше», «назад», «пауза», «играй») прямо на колонке без обращения к облаку.

6. **Полная автономность (Safe & Clean)**:
   - Системный раздел прошивки остаётся нетронутым (read-only).
   - Поддерживает стандартные каталоги YAM v2 (`$YAM_VAR`, `$YAM_RUN`) и автономную работу в `/data/spotify`.
   - Включает изолированный загрузчик **glibc 2.30+** (не ломает системные библиотеки станции).

## 🔑 Как получить Spotify API ключ (`spak_...`)

Для авторизации устройства Spotify Soloist требуется персональный токен разработчика:

1. Перейдите в [Spotify Developer Dashboard](https://developer.spotify.com/dashboard) и войдите в аккаунт с подпиской Spotify Premium.
2. Нажмите **Create app**:
   - **App name**: `Foxify` (или любое другое)
   - **App description**: `Spotify Connect on Mini 2`
   - **Redirect URIs**: `http://localhost/callback`
   - Отметьте **Web API** и примите соглашение.
3. Сохраните приложение и откройте вкладку **Settings** (или раздел [Spotify Soloist Developer Portal](https://developer.spotify.com/dashboard/soloist)).
4. Скопируйте сгенерированный ключ клиента вида `spak_...`.

## 🚀 Установка

### Вариант 1. Через YAM (рекомендуется)
Если на вашей Станции установлен YAM:
```bash
# Установка из официального реестра
yam install avelc/foxify

# Или установка локального архива
yam install foxify-yandexmini_2.yampkg
```

После установки настройте ключ:
```bash
foxify set-key spak_ваш_ключ_здесь
foxify start
```

---

### Вариант 2. Через ADB (без YAM)
Подключитесь к колонке:
```bash
adb connect 192.168.1.XX:5555
```
Запустите установщик из каталога проекта:
```bash
chmod +x install.sh
./install.sh adb
```
Инсталлятор запросит ваш ключ `spak_...`, имя колонки, загрузит файлы в `/data/spotify` и сразу запустит плеер.

---

### Вариант 3. Через SSH
```bash
./install.sh root@192.168.1.XX
```

## 🎛️ Команды управления (CLI)

После установки в системе доступна удобная утилита `foxify` (или скрипт `/data/spotify/service.sh` при ручной установке):

### Настройка
```bash
foxify set-key spak_XXXXX...   # Сохранить API ключ Spotify
foxify set-name "Спальня"      # Задать имя колонки в приложении Spotify
foxify curve on                # ⚡ Включить экспериментальную перцептивную кривую
foxify curve off               # Выключить (вернуться к стандартной линейной)
```

### Статус и логи
```bash
foxify status                  # Показать статус, громкость и текущий трек
foxify logs                    # Просмотр журнала в реальном времени
```

### Воспроизведение
```bash
foxify now                     # Показать информацию о текущей песне
foxify play                    # Возобновить музыку
foxify pause                   # Поставить на паузу
foxify next                    # Следующий трек
foxify prev                    # Предыдущий трек
foxify volume 35               # Установить громкость (0–100%)
```

### Служба
```bash
foxify start                   # Запустить сервис
foxify stop                    # Остановить сервис
foxify restart                 # Перезапустить сервис
```

## 🔄 Автозапуск при включении (без YAM)

При установке через YAM сервис запускается супервизором автоматически.
Если вы устанавливали вручную через ADB/SSH, добавьте запуск в `/data/auto_run.sh`:
```bash
echo "/data/spotify/service.sh start" >> /data/auto_run.sh
chmod +x /data/auto_run.sh
```

## 💡 Важный совет по акустике

Корпус Яндекс Станции Мини 2 спроектирован с фазоинвертором и низкочастотными каналами, направленными вниз в основание.
- **Ставьте колонку на плотную, массивную поверхность** (деревянный стол, каменная столешница, полка без зазоров).
- Если колонка висит в воздухе, стоит на решётке или на тонкой подвесной доске с пустотой под ней, возникает фазовое самопогашение баса и дребезг. Установка на плотную плоскость сразу возвращает глубокий чистый бас.
